📸 КАК ДОБАВЛЯТЬ ФОТОГРАФИИ - КРАТКАЯ ВЕРСИЯ:
================================================

СПОСОБ 1: Через Админ-Панель (РЕКОМЕНДУЕТСЯ!)
----------------------------------------------
1. Откройте: /admin/login
2. Войдите с логином и паролем администратора
3. Перейдите в раздел "Меню"
4. Нажмите "+ Добавить блюдо"
5. Заполните название, цену, категорию
6. В поле "Фото":
   - Либо загрузите файл с компьютера (JPG/PNG, до 5 МБ)
   - Либо вставьте ссылку на фото (например, с Unsplash)
7. Нажмите "Сохранить"

✅ ГОТОВО! Фото появится на сайте в меню

СПОСОБ 2: Через базу данных Prisma Studio
------------------------------------------
1. Запустите: npx prisma studio
2. Откройте таблицу "product_images"
3. Нажмите "Add record"
4. Заполните:
   - url: ссылка на фото
   - productId: ID товара
   - isMain: true
   - sortOrder: 0
5. Сохраните

СПОСОБ 3: Через API
-------------------
POST /api/products
Body:
{
  "name": "Ролл Дракон",
  "price": 540,
  "categoryId": "uuid-категории",
  "images": [{
    "url": "https://example.com/photo.jpg",
    "isMain": true
  }]
}

📁 ГДЕ ХРАНЯТСЯ ФОТОГРАФИИ:
===========================
- База данных: таблица "product_images"
- Структура: url (ссылка или base64), productId, isMain
- Один товар может иметь несколько фотографий

🖼️ РЕКОМЕНДАЦИИ ПО ФОТО:
==========================
- Формат: JPG или PNG
- Размер: 800x800 px (квадратное)
- Вес: до 500 КБ
- Фон: однотонный или размытый
