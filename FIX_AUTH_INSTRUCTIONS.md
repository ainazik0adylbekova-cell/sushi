# 🔧 Исправление проблемы с регистрацией и входом

## ❌ Проблема

При попытке регистрации или входа возникала ошибка:
**"Ошибка сервера. Попробуйте позже."**

## ✅ Что было исправлено

### 1. Проблема с ролями
Схема базы данных требует обязательное поле `roleId` для пользователя, но роли не создавались автоматически.

### 2. Исправленные файлы:
- ✅ `app/api/auth/register/route.ts` - Добавлено автоматическое создание роли "Пользователь"
- ✅ `app/api/auth/login/route.ts` - Добавлена загрузка роли пользователя
- ✅ `app/api/auth/me/route.ts` - Исправлено получение роли

### 3. Новые файлы:
- ✅ `scripts/init-roles.ts` - Скрипт инициализации ролей
- ✅ `init-roles.bat` - Batch файл для запуска скрипта
- ✅ `FIX_AUTH_INSTRUCTIONS.md` - Эта инструкция

## 🚀 Как исправить

### Вариант 1: Автоматическая инициализация (Рекомендуется)

Дважды кликните на файл:
```
init-roles.bat
```

Этот скрипт:
1. Установит `tsx` (если нужно)
2. Создаст базовые роли в БД ("Пользователь" и "Администратор")

### Вариант 2: Через командную строку

```bash
# Установите tsx
npm install -D tsx

# Запустите скрипт инициализации ролей
npx tsx scripts/init-roles.ts
```

### Вариант 3: Вручную через Prisma Studio

1. Откройте Prisma Studio:
```bash
npm run db:studio
```

2. Перейдите в таблицу `roles`

3. Создайте две роли:
   - **Роль 1:**
     - name: `Пользователь`
     - description: `Обычный пользователь системы`
   
   - **Роль 2:**
     - name: `Администратор`
     - description: `Администратор системы с полным доступом`

## 🧪 Тестирование

После инициализации ролей:

1. **Остановите dev сервер** (если запущен)
   - Нажмите `Ctrl+C` в терминале

2. **Запустите dev сервер заново:**
```bash
npm run dev
```

3. **Попробуйте зарегистрироваться:**
   - Откройте http://localhost:3000/register
   - Заполните форму
   - Нажмите "Зарегистрироваться"

4. **Или попробуйте войти:**
   - Откройте http://localhost:3000/login
   - Введите email и пароль
   - Нажмите "Войти"

## 📊 Проверка в базе данных

Откройте Prisma Studio:
```bash
npm run db:studio
```

Проверьте:
1. **Таблица `roles`** - должны быть 2 роли:
   - Пользователь
   - Администратор

2. **Таблица `users`** - после регистрации появится новый пользователь с `roleId`

## 🔍 Логи для отладки

Если проблема остаётся, проверьте консоль dev сервера на наличие ошибок:

```
[/api/auth/register] Error: ...
[/api/auth/login] Error: ...
```

## ❗ Важные замечания

### Автоматическое создание роли
Теперь при регистрации роль "Пользователь" создаётся автоматически, если её нет в БД. Но лучше запустить `init-roles.bat` один раз, чтобы создать обе роли сразу.

### Миграции
Если вы изменяли схему Prisma, выполните:
```bash
npm run db:push
```

### Генерация Prisma Client
Если возникают ошибки с Prisma:
```bash
npm run db:generate
```
или запустите `generate-prisma.bat`
