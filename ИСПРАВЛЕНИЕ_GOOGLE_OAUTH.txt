ПРОБЛЕМА: "Не удалось войти через Google"

РЕШЕНИЕ:

✅ ШАГ 1: .env файл исправлен!
   - Убраны лишние пробелы
   - GOOGLE_CLIENT_SECRET_ID → GOOGLE_CLIENT_SECRET
   - Добавлены NEXT_PUBLIC_APP_URL и JWT_SECRET

✅ ШАГ 2: ОБЯЗАТЕЛЬНО перезапустите сервер!

   В терминале:
   1. Остановите сервер: Ctrl+C
   2. Запустите заново: npm run dev

✅ ШАГ 3: Проверьте Google Cloud Console

   Откройте: https://console.cloud.google.com/apis/credentials

   Проверьте что в "Authorized redirect URIs" есть:
   ✓ http://localhost:3000/api/auth/google/callback

   Если нет - добавьте и сохраните!

════════════════════════════════════════════════════════════════
  ТЕСТИРОВАНИЕ
════════════════════════════════════════════════════════════════

1. Перезапустите dev сервер (ОБЯЗАТЕЛЬНО!)
2. Откройте http://localhost:3000/login
3. Нажмите кнопку "Войти через Google"
4. Выберите аккаунт Google
5. Должно сработать! ✨
