# 🔍 ДИАГНОСТИКА ПРОБЛЕМЫ С КАРТОЙ 2ГИС

## ❌ ЧТО БЫЛО СЛОМАНО:

### 1. Неправильная инициализация DG
**Проблема:** 
```javascript
(window as any).DG?.then(() => {
  setMapLoaded(true);
})
```

**Что не так:**
- `DG` может быть **либо функцией**, либо **объектом**
- В современных версиях 2GIS API, DG часто загружается как объект
- Код проверял только вариант с функцией

**Исправлено:**
```javascript
const DGLoader = (window as any).DG;

if (typeof DGLoader === "function") {
  // Вариант 1: DG - функция-loader
  DGLoader.then(() => {
    console.log("2GIS API инициализирован через .then()");
    setMapLoaded(true);
  })
} else if (typeof DGLoader === "object" && DGLoader !== null) {
  // Вариант 2: DG - уже готовый объект API
  if (typeof DGLoader.map === "function") {
    console.log("2GIS API готов к использованию");
    setMapLoaded(true);
  }
}
```

---

### 2. Отсутствие параметра pkg=full
**Проблема:**
```javascript
script.src = "https://maps.api.2gis.ru/2.0/loader.js";
```

**Что не так:**
- Базовая версия API может не включать все необходимые функции
- Отсутствует полный пакет возможностей

**Исправлено:**
```javascript
script.src = "https://maps.api.2gis.ru/2.0/loader.js?pkg=full";
```

---

### 3. Повторная инициализация карты
**Проблема:**
- При каждом ре-рендере компонента карта создавалась заново
- Не было проверки на уже созданную карту

**Исправлено:**
```javascript
const mapInitialized = useRef(false);

useEffect(() => {
  if (mapInitialized.current) return;
  // ... инициализация
  mapInitialized.current = true;
}, [mapLoaded]);
```

### 5. Не работал клик на филиал в списке
**Проблема:**
- Клик на филиал только выделял его
- Карта не перемещалась к выбранному филиалу

**Исправлено:**
```javascript
const handleBranchClick = (branch: Branch) => {
  setSelectedBranch(branch);
  
  if (mapRef.current) {
    // Перемещаем карту к выбранному филиалу
    mapRef.current.setView([branch.lat, branch.lng], 15, { animate: true });
  }
};
```

## ❗ ЕСЛИ КАРТА НЕ ЗАГРУЖАЕТСЯ:

### Проверьте консоль на ошибки:

#### Ошибка 1: "Failed to load resource"
**Причина:** Проблемы с интернетом или блокировка домена

**Решение:**
1. Проверьте интернет-соединение
2. Отключите блокировщик рекламы
3. Проверьте файрвол

#### Ошибка 2: "DG is not a function"
**Причина:** Скрипт загрузился некорректно

**Решение:**
1. Очистите кеш браузера
2. Перезагрузите страницу (Ctrl+F5)
3. Проверьте URL скрипта

#### Ошибка 3: "Cannot read property 'map' of undefined"
**Причина:** API не инициализировался

**Решение:**
1. Подождите 2-3 секунды
2. Проверьте что `mapLoaded === true`
3. Проверьте логи в консоли

#### Ошибка 4: Карта белая/пустая
**Причина:** Контейнер без размеров или неверные координаты

**Решение:**
1. Проверьте что `#map` имеет `height: 600px`
2. Проверьте координаты в `lib/branches.ts`
3. Координаты должны быть для Бишкека: lat ~42.8, lng ~74.5

## 📊 КООРДИНАТЫ ФИЛИАЛОВ:

Текущие координаты - **демонстрационные**!

### Формат координат 2GIS:
```typescript
[lat, lng]  // [широта, долгота]
```

### Для Бишкека:
- Широта (lat): 42.8 - 42.9
- Долгота (lng): 74.5 - 74.6

### Как получить реальные координаты:

1. Откройте https://2gis.kg
2. Найдите адрес
3. Кликните на точку
4. В URL будет: `...74.56789,42.87654`
5. Это lng, lat
6. В коде используйте: `[42.87654, 74.56789]`

**ВАЖНО:** 2GIS использует порядок [lat, lng], не [lng, lat]!
