# 🖼️ Как добавить изображения для продуктов

## Быстрый способ (через скрипт)

### 1. Сохраните изображение в папку `public`

```
public/
├── filadel.jpg       ✅ Уже добавлен
├── colif.jpg         ✅ Уже добавлен  
├── set.classik.jpg   ✅ Уже добавлен
└── новое-блюдо.jpg   ← Добавьте сюда
```

### 2. Добавьте продукт в скрипт

Откройте файл: `scripts/update-product-images.js`

Добавьте в объект `productImages`:

```javascript
const productImages = {
  // ... существующие продукты ...
  
  'slug-produkta': {
    name: 'Название продукта',
    image: '/novoe-blyudo.jpg',
    altText: 'Описание для SEO'
  }
};
```

**Важно:** `slug-produkta` должен совпадать со slug продукта в базе данных!

### 3. Запустите скрипт

```bash
update-images.bat
```

или

```bash
node scripts/update-product-images.js
```

## Ручной способ (через админку)

### 1. Сохраните изображение

Поместите файл в папку `public`:
```
public/myproduct.jpg
```

### 2. Войдите в админку

```
http://localhost:3000/admin/login
```

### 3. Откройте редактирование продукта

1. Перейдите в **Меню**
2. Найдите нужный продукт
3. Нажмите **Редактировать**

### 4. Добавьте изображение

В поле "URL изображения" введите:
```
/myproduct.jpg
```

### 5. Сохраните

Нажмите **Сохранить** - изображение привязано к продукту!

## Через Prisma Studio

### 1. Откройте Prisma Studio

```bash
open-studio.bat
```

или

```bash
npm run db:studio
```

### 2. Перейдите к таблице ProductImage

### 3. Добавьте новую запись

```
url: /myproduct.jpg
altText: Описание продукта
isMain: true
sortOrder: 0
productId: [ID продукта из таблицы Product]
```

## Форматы изображений

Рекомендуемые форматы:
- ✅ JPG - для фотографий блюд
- ✅ PNG - для изображений с прозрачностью
- ✅ WebP - для оптимизации (лучшее сжатие)

Рекомендуемые размеры:
- Минимум: 800x600px
- Оптимально: 1200x900px
- Максимум: 2000x1500px

## Оптимизация изображений

Перед добавлением рекомендуется сжать изображения:

### Онлайн инструменты:
- https://tinypng.com/
- https://squoosh.app/
- https://imagecompressor.com/

### Локально:
```bash
# Установите sharp
npm install -g sharp-cli

# Оптимизируйте изображение
sharp -i input.jpg -o output.jpg --quality 80 --resize 1200,900
```

## Несколько изображений для одного продукта

Если нужно добавить галерею:

```javascript
// В скрипте
await prisma.productImage.createMany({
  data: [
    {
      productId: product.id,
      url: '/product-1.jpg',
      isMain: true,
      sortOrder: 0
    },
    {
      productId: product.id,
      url: '/product-2.jpg',
      isMain: false,
      sortOrder: 1
    },
    {
      productId: product.id,
      url: '/product-3.jpg',
      isMain: false,
      sortOrder: 2
    }
  ]
});
```

## Проверка

После добавления изображений:

1. Запустите сервер: `START_SERVER.bat`
2. Откройте меню: http://localhost:3000/menu
3. Проверьте, что изображения отображаются

## Troubleshooting

### ❌ Изображение не отображается

**Проблема:** Файл не найден (404)

**Решение:**
1. Проверьте, что файл находится в папке `public`
2. Проверьте путь (должен начинаться с `/`)
3. Проверьте имя файла (регистр важен!)

### ❌ Изображение слишком большое

**Проблема:** Медленная загрузка страницы

**Решение:**
1. Сжмите изображение (см. раздел "Оптимизация")
2. Уменьшите разрешение до 1200x900px
3. Используйте формат WebP

### ❌ Неправильная пропорция

**Проблема:** Изображение искажено

**Решение:**
1. Обрежьте изображение до пропорции 4:3 или 16:9
2. Используйте `object-fit: cover` в CSS
3. Подготовьте изображение в графическом редакторе

## Дополнительно

### Массовое добавление изображений

Если нужно добавить много изображений, создайте расширенный скрипт:

```javascript
// scripts/bulk-import-images.js
const images = [
  { slug: 'product-1', image: '/product-1.jpg' },
  { slug: 'product-2', image: '/product-2.jpg' },
  // ... еще продукты
];

for (const item of images) {
  const product = await prisma.product.findUnique({
    where: { slug: item.slug }
  });
  
  if (product) {
    await prisma.productImage.create({
      data: {
        productId: product.id,
        url: item.image,
        isMain: true
      }
    });
  }
}
```
