# 🔍 Как проверить, почему не работает карта 2ГИС

## Шаг 1: Откройте тестовую страницу

1. Откройте браузер
2. Перейдите по адресу: **http://localhost:3000/test-2gis.html**
3. Откройте консоль разработчика (нажмите **F12**)

### Что вы должны увидеть:

✅ **Если всё работает:**
- 4 зелёных галочки в статусе
- Карта с 13 оранжевыми маркерами
- В консоли зелёный текст без ошибок

❌ **Если не работает:**
- Красные крестики в статусе
- Пустой контейнер вместо карты
- Ошибки в консоли (красный текст)

---

## Шаг 2: Проверьте основную страницу

1. Перейдите по адресу: **http://localhost:3000/branches**
2. Смотрите консоль (F12)

### Что искать в консоли:

✅ **Правильная последовательность:**
```
Загрузка 2GIS API...
Скрипт 2GIS загружен
2GIS API инициализирован
Инициализация карты 2GIS...
Карта создана, добавляем маркеры...
Добавление маркера 1: Суши Жейм - Центр [42.8746, 74.5698]
Добавление маркера 2: Суши Жейм - Ала-Арча [42.8846, 74.5798]
...
Добавлено маркеров: 13
Масштаб карты подогнан под все маркеры
Карта успешно инициализирована!
```

❌ **Частые ошибки:**

### Ошибка 1: "Failed to load resource"
```
GET https://maps.api.2gis.ru/2.0/loader.js net::ERR_FAILED
```

**Причина:** Нет интернета или блокировка

**Решение:**
- Проверьте интернет-соединение
- Отключите VPN/прокси
- Отключите блокировщик рекламы
- Проверьте антивирус/файрвол

### Ошибка 2: "DG is not a function"
```
TypeError: DG is not a function
```

**Причина:** Неправильная инициализация

**Решение:**
- Очистите кеш браузера (Ctrl+Shift+Delete)
- Перезагрузите страницу (Ctrl+F5)
- Проверьте что URL скрипта: `https://maps.api.2gis.ru/2.0/loader.js?pkg=full`

### Ошибка 3: "Cannot read property 'map' of undefined"
```
TypeError: Cannot read property 'map' of undefined
```

**Причина:** API не успел инициализироваться

**Решение:**
- Подождите 2-3 секунды и обновите страницу
- Проверьте скорость интернета
- Откройте тестовую страницу test-2gis.html

### Ошибка 4: Карта белая/пустая (без ошибок)
```
Карта создана, но ничего не видно
```

**Причина:** Неверные координаты или размеры контейнера

**Решение:**
- Проверьте, что контейнер `#map` имеет высоту 600px
- Проверьте координаты в `lib/branches.ts`
- Для Бишкека: lat ≈ 42.8, lng ≈ 74.5

## Шаг 3: Проверка кода

### Проверьте файл `app/branches/page.tsx`:

1. **Правильная загрузка скрипта:**
```typescript
script.src = "https://maps.api.2gis.ru/2.0/loader.js?pkg=full";
//                                                     ^^^^^^^^ важно!
```

2. **Правильная инициализация DG:**
```typescript
const DGLoader = (window as any).DG;
if (typeof DGLoader === "function") {
  DGLoader.then(() => {
    setMapLoaded(true);
  })
}
```

3. **Правильный порядок координат:**
```typescript
DG.marker([branch.lat, branch.lng], { ... })
//         ^^^^^^^^^^^  ^^^^^^^^^^^
//         СНАЧАЛА lat, ПОТОМ lng для 2GIS!
```

---

## Шаг 4: Проверка координат

Откройте файл `lib/branches.ts` и проверьте:

### ✅ Правильный формат:
```typescript
{
  lat: 42.8746,  // Широта для Бишкека: 42.8 - 42.9
  lng: 74.5698,  // Долгота для Бишкека: 74.5 - 74.6
}
```

### ❌ Неправильные координаты:
- lat = 0, lng = 0 (центр океана)
- lat > 90 или lat < -90 (невозможно)
- lng > 180 или lng < -180 (невозможно)
- lat и lng перепутаны местами

## Если ничего не помогло:

1. **Скопируйте ВСЁ из консоли браузера** (F12 → Console → правый клик → Save as...)

2. **Сделайте скриншот страницы**

3. **Проверьте вкладку Network** (F12 → Network):
   - Найдите запрос к `loader.js`
   - Какой статус? (200 = OK, 404 = не найден, 0 = блокировка)
   - Какой размер? (должен быть > 0)

4. **Откройте прямо в браузере:**
   ```
   https://maps.api.2gis.ru/2.0/loader.js?pkg=full
   ```
   Должен загрузиться JavaScript-файл. Если нет - проблема с сетью.
