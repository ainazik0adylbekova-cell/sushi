## Как протестировать:

### Вариант 1: Через браузер (рекомендуется)
1. Откройте браузер
2. Перейдите на: **http://localhost:3000/login**
3. Нажмите на таб "Регистрация"
4. Заполните форму:
   - **Имя:** Иван Иванов
   - **Email:** test@example.com
   - **Телефон:** +996500123456 (необязательно)
   - **Пароль:** test123456
   - **Подтверждение:** test123456
5. Нажмите "Зарегистрироваться"
6. После успешной регистрации вы будете перенаправлены на главную страницу

После регистрации в консоли сервера (терминал где запущен `npm run dev`) вы увидите:

После входа:

## Структура данных:

### Регистрация (POST /api/auth/register)
**Запрос:**
```json
{
  "name": "Иван Иванов",
  "email": "ivan@example.com",
  "phone": "+996500123456",
  "password": "securepass123"
}
```

**Успешный ответ (201):**
```json
{
  "success": true,
  "user": {
    "id": "uuid-here",
    "name": "Иван Иванов",
    "email": "ivan@example.com",
    "role": "Пользователь"
  }
}
```

**Ошибка (400/409/500):**
```json
{
  "error": "Этот email уже зарегистрирован"
}
```

### Вход (POST /api/auth/login)
**Запрос:**
```json
{
  "email": "ivan@example.com",
  "password": "securepass123"
}
```

**Успешный ответ (200):**
```json
{
  "success": true,
  "user": {
    "id": "uuid-here",
    "name": "Иван Иванов",
    "email": "ivan@example.com",
    "role": "Пользователь"
  }
}
```

## Сессии:

- Используется JWT токен
- Хранится в HTTP-only cookie `syshi_session`
- Срок действия: 30 дней
- Автоматически обновляется при каждом запросе

## Безопасность:

- ✅ Пароли хешируются с помощью bcrypt (10 раундов соли)
- ✅ Email нормализуется (toLowerCase, trim)
- ✅ HTTP-only cookies (защита от XSS)
- ✅ Валидация на клиенте и сервере
- ✅ Защита от SQL-инъекций (Prisma ORM)

## Проблемы и решения:

### Если не работает регистрация:

1. **Проверьте базу данных:**
   ```bash
   # Убедитесь что DATABASE_URL правильный в .env
   # Проверьте существует ли таблица roles:
   node -e "const {PrismaClient} = require('@prisma/client'); const p = new PrismaClient(); p.role.findMany().then(r => console.log('Roles:', r)).finally(() => p.$disconnect())"
   ```

2. **Проверьте логи сервера:**
   - Откройте терминал где запущен сервер
   - Посмотрите сообщения `[REGISTER]` и `[LOGIN]`
   - Если есть ошибки - они будут показаны с деталями

3. **Проверьте консоль браузера (F12):**
   - Откройте DevTools (F12)
   - Перейдите на вкладку "Network"
   - Попробуйте зарегистрироваться
   - Посмотрите ответ от `/api/auth/register`
