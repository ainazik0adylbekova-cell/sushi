# 🔧 Исправление регистрации

## 🐛 Проблема
При попытке регистрации появляется ошибка:
```
Ошибка сервера. Попробуйте позже.
```

## 🎯 Причина
В базе данных отсутствуют роли пользователей.

## ✅ Решение

### Вариант 1: Автоматическая инициализация (Рекомендуется)

Я добавила автоматическое создание ролей прямо в код регистрации. Просто перезапустите сервер:

```bash
Ctrl+C
npm run dev
```

Теперь при первой регистрации роли создадутся автоматически!

### Вариант 2: Ручная инициализация через скрипт

Если автоматика не сработала, запустите скрипт:

```bash
npx tsx scripts/init-roles.ts
```

Этот скрипт создаст в базе данных:
- ✅ Роль "Пользователь"
- ✅ Роль "Администратор"

## 🧪 Проверка

1. Откройте http://localhost:3000
2. Нажмите "Войти" → "Регистрация"
3. Заполните форму:
   - Имя: Ваше имя
   - Email: test@example.com
   - Телефон: +996 500 123 456 (необязательно)
   - Пароль: минимум 6 символов
4. Нажмите "Зарегистрироваться"

**Должно сработать!** ✅

## 📝 Что было исправлено

### 1. Улучшенная обработка ошибок
- Добавлен try-catch для создания ролей
- Более детальные логи ошибок
- Fallback на любую существующую роль

### 2. Автоматическое создание ролей
- При регистрации первого пользователя роли создаются автоматически
- Не нужно запускать отдельные скрипты

### 3. Скрипт инициализации
- Создан `scripts/init-roles.ts`
- Можно запустить вручную если нужно

## 🔍 Отладка

Если регистрация всё ещё не работает, проверьте логи сервера в терминале где запущен `npm run dev`.

Вы увидите:
```
[/api/auth/register] Полная ошибка: ...
```

Это поможет понять что именно пошло не так.

### Возможные проблемы:

#### 1. База данных недоступна
**Симптом:** `PrismaClientKnownRequestError`
**Решение:** Проверьте `DATABASE_URL` в `.env`

#### 2. Таблицы не созданы
**Симптом:** `Table 'roles' doesn't exist`
**Решение:** Запустите миграции:
```bash
npx prisma migrate dev
```

#### 3. Дубликат email
**Симптом:** "Этот email уже зарегистрирован"
**Решение:** Используйте другой email или удалите старого пользователя

## 🎉 После исправления

Регистрация будет работать автоматически:
1. Пользователь заполняет форму
2. Создаются роли (если их нет)
3. Создаётся пользователь
4. Пользователь автоматически входит в систему
5. Перенаправление на главную страницу

**Без ошибок!** ✨

## 📚 Технические детали

### Структура ролей:

```sql
CREATE TABLE roles (
  id VARCHAR(36) PRIMARY KEY,
  name VARCHAR(50) UNIQUE NOT NULL,
  description TEXT
);

INSERT INTO roles (name, description) VALUES
  ('Пользователь', 'Обычный пользователь сайта'),
  ('Администратор', 'Администратор системы');
```

### Связь с пользователями:

```sql
CREATE TABLE users (
  id VARCHAR(36) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE,
  phone VARCHAR(20) UNIQUE,
  password VARCHAR(255) NOT NULL,
  role_id VARCHAR(36) NOT NULL,
  FOREIGN KEY (role_id) REFERENCES roles(id)
);
```
