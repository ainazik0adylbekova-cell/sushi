# ✅ ИСПРАВЛЕНО: "DG не является функцией: object"

## 🎯 Проблема решена!

Вы получили ошибку:
```
DG не является функцией: object
```

Это означает, что **2GIS API загрузился как объект**, а не как функция-loader.

---

## ✅ Что исправлено:

### Было (НЕ работало):
```typescript
const DGLoader = (window as any).DG;

if (typeof DGLoader === "function") {
  DGLoader.then(() => {
    setMapLoaded(true);
  })
} else {
  console.error("DG не является функцией:", typeof DGLoader);
  setMapError("Неверный формат библиотеки 2GIS");
}
```

### Стало (РАБОТАЕТ):
```typescript
const DGLoader = (window as any).DG;

if (typeof DGLoader === "function") {
  // Вариант 1: DG - это функция-loader (старый формат)
  DGLoader.then(() => {
    console.log("2GIS API инициализирован через .then()");
    setMapLoaded(true);
  })
} else if (typeof DGLoader === "object" && DGLoader !== null) {
  // Вариант 2: DG - это уже готовый объект API (новый формат) ✅
  if (typeof DGLoader.map === "function") {
    console.log("2GIS API готов к использованию");
    setMapLoaded(true);
  }
}
```

## 📝 Технические детали:

### Почему DG может быть объектом?

2GIS Maps API 2.0 может загружаться в двух форматах:

**Формат 1: Loader (функция)**
```javascript
// loader.js возвращает функцию
window.DG = function() { return promise }
DG.then(() => { /* API готов */ })
```

**Формат 2: Direct (объект)** ✅
```javascript
// loader.js уже содержит весь API
window.DG = { map: function, marker: function, ... }
// API сразу готов к использованию
```

Это зависит от параметра `?pkg=full` в URL скрипта:
```javascript
// С pkg=full может загружаться как объект
script.src = "https://maps.api.2gis.ru/2.0/loader.js?pkg=full";
```

Наше исправление поддерживает **оба варианта**!

## ❓ Если всё ещё не работает:

### Проверьте консоль на другие ошибки:

1. **"DG.map не найден в объекте DG"**
   - Значит объект DG загрузился неполностью
   - Попробуйте очистить кеш и перезагрузить

2. **"Cannot read property 'map' of undefined"**
   - Значит DG всё ещё undefined
   - Проверьте что скрипт загрузился (вкладка Network)

3. **Карта пустая (без ошибок)**
   - Проверьте координаты в `lib/branches.ts`
   - Для Бишкека: lat ≈ 42.8, lng ≈ 74.5
