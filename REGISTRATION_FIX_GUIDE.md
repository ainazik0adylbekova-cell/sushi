# 🔧 Инструкция: Как исправить регистрацию

## Проблема
При попытке регистрации появляется ошибка "Ошибка сервера", потому что в базе данных нет роли "Пользователь".

## Решение

### Способ 1: Запуск скрипта инициализации (Рекомендуется)

1. **Откройте папку проекта** в проводнике Windows
2. **Найдите файл** `init-roles.bat`
3. **Дважды кликните** по нему
4. Дождитесь сообщения "Готово!" и закройте окно

Готово! Теперь регистрация должна работать.

---

### Способ 2: Через командную строку

1. Откройте терминал в папке проекта (PowerShell или CMD)
2. Выполните команду:

```bash
npx tsx scripts/init-roles.ts
```

3. Дождитесь успешного завершения

---

### Способ 3: Ручное добавление через SQL (если способы 1-2 не работают)

1. Откройте вашу базу данных Neon PostgreSQL
2. Выполните следующие SQL-запросы:

```sql
-- Создать роль "Пользователь"
INSERT INTO "Role" (id, name, description, "createdAt", "updatedAt")
VALUES (
  gen_random_uuid(),
  'Пользователь',
  'Обычный пользователь системы',
  NOW(),
  NOW()
)
ON CONFLICT (name) DO NOTHING;

-- Создать роль "Администратор"
INSERT INTO "Role" (id, name, description, "createdAt", "updatedAt")
VALUES (
  gen_random_uuid(),
  'Администратор',
  'Администратор системы с полным доступом',
  NOW(),
  NOW()
)
ON CONFLICT (name) DO NOTHING;
```

---

## Проверка

После выполнения любого из способов:

1. Перейдите на сайт
2. Нажмите "Регистрация"
3. Заполните форму:
   - Имя: ваше имя
   - Email: ваш email
   - Телефон: (необязательно)
   - Пароль: минимум 6 символов
4. Нажмите "Зарегистрироваться"

Если все прошло успешно, вы будете автоматически авторизованы!

---

## Почему это происходит?

Система регистрации автоматически создает роль "Пользователь" при первой регистрации, НО только если база данных уже была правильно инициализирована с Prisma. 

Скрипт `init-roles.ts` гарантирует, что необходимые роли существуют в базе данных перед первым использованием.

## Дополнительные команды

### Проверить существующие роли:
```bash
npx prisma studio
```
Откройте таблицу `Role` и проверьте наличие ролей "Пользователь" и "Администратор".

### Пересоздать базу данных (ВНИМАНИЕ: удалит все данные):
```bash
npx prisma migrate reset
npx prisma db push
npm run db:generate
npx tsx scripts/init-roles.ts
```

## Контакты

Если проблема не решена, проверьте:

- ✅ База данных Neon доступна
- ✅ Prisma Client сгенерирован (`npm run db:generate`)
