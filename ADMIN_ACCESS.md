## 🔑 Процесс входа (2FA через Telegram)

Система использует двухфакторную аутентификацию через Telegram для безопасности.

### Шаг 1: Ввод логина и пароля
1. Откройте `/admin/login`
2. Введите email: `admin@syshi.kg`
3. Введите пароль: `admin123`
4. Нажмите "Получить код в Telegram"

### Шаг 2: Получение кода в Telegram
1. Откройте Telegram
2. Найдите бота: `@sushi_jeim_bot` (или имя вашего бота)
3. Получите 6-значный код (действует 5 минут)

### Шаг 3: Ввод кода
1. Введите полученный код на странице входа
2. Нажмите "Войти в админку"
3. Вы будете перенаправлены на `/admin`

## ⚙️ Настройка Telegram бота

### Текущие настройки (.env):

```bash
TELEGRAM_BOT_TOKEN=8802398882:AAFs8OCyJ6BB3RjfU6pdSmYZmYdKHJ2g9PI
TELEGRAM_ADMIN_CHAT_ID=your_chat_id_here  # ⚠️ НУЖНО НАСТРОИТЬ!
```

### Как получить TELEGRAM_ADMIN_CHAT_ID:

1. **Запустите бота:**
   - Найдите вашего бота в Telegram: `@sushi_jeim_bot`
   - Нажмите `/start`

2. **Получите ваш Chat ID:**
   
   **Способ 1: Через специального бота**
   - Найдите в Telegram: `@userinfobot`
   - Нажмите `/start`
   - Бот покажет ваш ID

   **Способ 2: Через API**
   - Отправьте любое сообщение вашему боту
   - Откройте в браузере:
     ```
     https://api.telegram.org/bot8802398882:AAFs8OCyJ6BB3RjfU6pdSmYZmYdKHJ2g9PI/getUpdates
     ```
   - Найдите `"chat":{"id":123456789}` - это ваш Chat ID

3. **Обновите .env файл:**
   ```bash
   TELEGRAM_ADMIN_CHAT_ID=123456789  # ваш реальный ID
   ```

4. **Перезапустите сервер:**
   ```bash
   npm run dev
   ```

## 🔒 Безопасность

### Рекомендации:

1. **Измените пароль в продакшене!**
   
   В `.env` на сервере установите:
   ```bash
   ADMIN_PASSWORD=your_strong_password_here
   ```

2. **Используйте сильный пароль:**
   - Минимум 12 символов
   - Комбинация букв, цифр, спецсимволов
   - Не используйте `admin123` в продакшене!

3. **Настройте Telegram правильно:**
   - Используйте только свой личный Chat ID
   - Не делитесь токеном бота

4. **В Vercel добавьте переменные окружения:**
   - `ADMIN_EMAIL`
   - `ADMIN_PASSWORD`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_ADMIN_CHAT_ID`

## ❌ Решение проблем

### Проблема: "Неверный логин или пароль"
**Решение:**
- Проверьте, что в `.env` указаны правильные `ADMIN_EMAIL` и `ADMIN_PASSWORD`
- Перезапустите сервер после изменения `.env`

### Проблема: "Код не приходит в Telegram"
**Решение:**
- Проверьте `TELEGRAM_BOT_TOKEN` в `.env`
- Убедитесь, что `TELEGRAM_ADMIN_CHAT_ID` настроен правильно
- Запустите бота командой `/start`
- Проверьте логи сервера на наличие ошибок

### Проблема: "Неверный код"
**Решение:**
- Код действует только 5 минут
- Убедитесь, что вводите последний полученный код
- Попробуйте запросить новый код

### Проблема: "Access denied" после входа
**Решение:**
- Очистите cookies браузера
- Попробуйте войти заново
- Проверьте, что сессия создается корректно
