- **Имя:** Иван Тестов
- **Email:** ivan@test.com
- **Телефон:** +996500123456 (необязательно)
- **Пароль:** test123456
- **Подтверждение:** test123456

### 4. Нажмите "Зарегистрироваться"

### 5. Что должно произойти:
- ✅ Форма отправится

- Должны успешно войти

## Автоматические тесты

### Тест 1: Проверка базы данных
```bash
# Способ 1: Через батник
test-db.bat

# Способ 2: Через node
node test-db-connection.js
```

**Что проверяется:**
- Подключение к PostgreSQL
- Существование таблиц users и roles
- Наличие роли "Пользователь"
- Количество пользователей

**Ожидаемый результат:**
```
✅ Подключение к базе данных успешно!
✅ Найдено ролей: 1
   - Пользователь (ID: ...)
✅ Количество пользователей: X
✅ Все проверки пройдены!
```

### Тест 2: Полная проверка системы
```bash
# Способ 1: Через батник
test-all.bat

# Способ 2: Через node
node test-full-registration.js
```

**Что проверяется (8 тестов):**
1. Доступность сервера
2. Валидация пустых полей
3. Валидация email
4. Валидация пароля (минимум 6 символов)
5. Регистрация нового пользователя
6. Защита от дубликатов email
7. Вход с созданным аккаунтом
8. Защита от неверного пароля

**Ожидаемый результат:**
```
✅ 1. Доступность сервера
✅ 2. Валидация пустых полей
✅ 3. Валидация email
✅ 4. Валидация пароля
✅ 5. Регистрация пользователя
✅ 6. Защита от дубликатов
✅ 7. Вход пользователя
✅ 8. Защита паролей

Пройдено: 8/8 (100%)
🎉 ВСЕ ТЕСТЫ ПРОЙДЕНЫ!
```

## Проверка через DevTools (F12)

### Откройте DevTools в браузере:
1. Нажмите F12 или Ctrl+Shift+I
2. Перейдите на вкладку "Network"
3. Попробуйте зарегистрироваться
4. Найдите запрос `register`
5. Посмотрите ответ сервера

### Успешная регистрация (Status: 201):
```json
{
  "success": true,
  "user": {
    "id": "uuid",
    "name": "Иван Тестов",
    "email": "ivan@test.com",
    "role": "Пользователь"
  }
}
```

### Ошибка (Status: 400/409/500):
```json
{
  "error": "Описание ошибки"
}
```

## Проверка через curl

### Регистрация:
```bash
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"Test User\",\"email\":\"test@test.com\",\"password\":\"test123456\"}"
```

### Вход:
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"email\":\"test@test.com\",\"password\":\"test123456\"}"
```

## Если что-то не работает

### 1. Сервер не запускается:
```bash
# Убейте процесс на порту 3000
taskkill /PID <PID> /F

# Или измените порт
# В package.json измените команду dev на:
"dev": "next dev -p 3001"
```

### 2. База данных не подключается:
- Проверьте `DATABASE_URL` в файле `.env`
- Запустите `node test-db-connection.js`
- Смотрите файл `ДИАГНОСТИКА.md`

### 3. API возвращает 500:
- Проверьте логи сервера
- Запустите `node test-db-connection.js`
- Убедитесь что роль "Пользователь" существует

### 4. Форма не отправляется:
- Откройте DevTools (F12)
- Посмотрите вкладку Console на ошибки JavaScript
- Посмотрите вкладку Network на запросы

### 5. Пользователь создаётся, но не может войти:
- Проверьте что пароль хешируется правильно
- Проверьте логи сервера при входе
- Убедитесь что email сохраняется в нижнем регистре
