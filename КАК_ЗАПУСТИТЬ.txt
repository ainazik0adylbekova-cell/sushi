═══════════════════════════════════════════════════════════
  ШАГ 0: ИНИЦИАЛИЗАЦИЯ РОЛЕЙ (ВАЖНО!)
═══════════════════════════════════════════════════════════

Перед первым использованием запустите:
    init-roles.bat

Это создаст базовые роли пользователей в БД.
Запускать нужно ОДИН РАЗ!

ВАЖНО: После этого ОБЯЗАТЕЛЬНО перезапустите сервер!
   Ctrl+C → npm run dev

═══════════════════════════════════════════════════════════
  ШАГ 1: ПРОВЕРКА НАСТРОЙКИ
═══════════════════════════════════════════════════════════

Дважды кликните на файл:
    check-finik-setup.bat

Этот скрипт проверит, что все файлы на месте и Prisma 
клиент сгенерирован.

═══════════════════════════════════════════════════════════
  ШАГ 2: ЗАПУСК DEV СЕРВЕРА
═══════════════════════════════════════════════════════════

Откройте командную строку (cmd) в папке проекта и выполните:

    npm run dev

Сервер запустится на http://localhost:3000

═══════════════════════════════════════════════════════════
  ШАГ 3: ТЕСТИРОВАНИЕ ОПЛАТЫ
═══════════════════════════════════════════════════════════

1. Откройте браузер: http://localhost:3000
2. Перейдите в "Меню"
3. Добавьте блюда в корзину
4. Нажмите на иконку корзины
5. Нажмите "Оформить заказ"
6. Войдите в систему (или зарегистрируйтесь)
7. Заполните форму доставки
8. Нажмите кнопку "Оплатить 5 сом"
9. Вас перенаправит на страницу Finik Pay
10. Отсканируйте QR-код и оплатите

═══════════════════════════════════════════════════════════
  ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
═══════════════════════════════════════════════════════════

ОШИБКА: "Ошибка сервера" при регистрации/входе
РЕШЕНИЕ: Запустите init-roles.bat (один раз)

ОШИБКА: PrismaClientValidationError
РЕШЕНИЕ: Запустите generate-prisma.bat (дважды кликните)

ОШИБКА: Не могу создать платёж
РЕШЕНИЕ: Проверьте, что вы вошли в систему

ОШИБКА: Webhook не приходит (локально)
РЕШЕНИЕ: Используйте ngrok для туннелирования
          См. FINIK_SETUP_INSTRUCTIONS.md
