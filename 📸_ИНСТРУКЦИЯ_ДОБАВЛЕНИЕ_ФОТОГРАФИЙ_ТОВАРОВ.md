# 📸 Инструкция: Как добавлять фотографии товаров в меню

## 🎯 Способ 1: Через Админ-Панель (САМЫЙ ПРОСТОЙ!)

### Шаг 1: Войдите в админ-панель
1. Откройте сайт: https://ваш-сайт.vercel.app/admin/login
2. Введите логин и пароль администратора
3. После входа вы попадёте в админ-панель

### Шаг 2: Перейдите в раздел "Меню"
1. В боковом меню нажмите **"Меню"** или **"Товары"**
2. Вы увидите список всех блюд

### Шаг 3: Добавьте новое блюдо с фотографией
1. Нажмите кнопку **"+ Добавить блюдо"** (или "Новый товар")
2. Заполните форму:
   - **Название**: например, "Ролл Дракон"
   - **Категория**: выберите из списка (Роллы, Суши, Сеты и т.д.)
   - **Цена**: укажите цену в сомах
   - **Вес**: например, "260 г" или "8 шт"
   - **Описание**: краткое описание блюда
   
3. **ДОБАВЛЕНИЕ ФОТОГРАФИИ:**
   
   **Вариант А: Загрузка файла с компьютера**
   - Нажмите на область **"Загрузить фото"** или **"+"**
   - Выберите файл с компьютера
   - ✅ Рекомендуемый формат: JPG или PNG
   - ✅ Максимальный размер: 5 МБ
   - ✅ Рекомендуемый размер: 800x800 px (квадратное фото)
   
   **Вариант Б: Ссылка на фото из интернета**
   - Переключитесь на вкладку **"URL"**
   - Вставьте ссылку на фото (например, с Unsplash)
   - Пример: `https://images.unsplash.com/photo-123...`

4. Нажмите **"Сохранить"** или **"Создать"**

### Шаг 4: Редактирование существующего блюда
1. В списке блюд найдите нужное
2. Нажмите кнопку **"Редактировать"** (иконка карандаша)
3. В поле "Фото" загрузите новое изображение
4. Нажмите **"Сохранить"**

## 📂 Способ 2: Через Базу Данных (для опытных)

### Где хранятся товары?
Товары хранятся в базе данных PostgreSQL в таблице `products`.
Фотографии хранятся в таблице `product_images`.

### Структура базы данных:

#### Таблица `products` (товары):
```
- id: UUID товара
- name: Название
- slug: URL-ссылка
- description: Описание
- price: Цена
- weight: Вес/количество
- categoryId: ID категории
- isAvailable: Доступность
```

#### Таблица `product_images` (фотографии):
```
- id: UUID фотографии
- url: Ссылка на изображение (base64 или URL)
- productId: ID товара
- isMain: Главная фотография (true/false)
- sortOrder: Порядок сортировки
```

### Как добавить фото через БД:
1. Откройте Prisma Studio (если установлено): `npx prisma studio`
2. Перейдите в таблицу `product_images`
3. Нажмите **"Add record"**
4. Заполните поля:
   - `url`: вставьте ссылку на фото или base64
   - `productId`: ID товара (скопируйте из таблицы `products`)
   - `isMain`: поставьте `true` для главного фото
   - `sortOrder`: 0 (для первого фото)

## 🌐 Способ 3: Через API (программно)

### Добавление товара с фото через API:

**Endpoint:** `POST /api/products`

**Пример запроса:**
```javascript
fetch('/api/products', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'Ролл Дракон',
    description: 'Угорь, авокадо, икра тобико',
    price: 540,
    weight: '280',
    categoryId: 'uuid-категории-роллов',
    isAvailable: true,
    images: [
      {
        url: 'https://images.unsplash.com/photo-123...',
        isMain: true,
        sortOrder: 0
      }
    ]
  })
})
```

### Обновление фото существующего товара:

**Endpoint:** `PUT /api/products/:id`

```javascript
fetch('/api/products/uuid-товара', {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    images: [
      {
        url: 'https://новая-ссылка-на-фото.jpg',
        isMain: true,
        sortOrder: 0
      }
    ]
  })
})
```

### Основные файлы:

1. **Админ-панель меню:**

## 🖼️ Рекомендации по фотографиям:

### ✅ Хорошие практики:
- **Формат**: JPG или PNG
- **Размер**: 800x800 px (квадратное)
- **Вес файла**: до 500 КБ (лучше сжимать)

## ❓ Частые вопросы:

### 1. Как заменить существующую фотографию?
- Через админ-панель: Редактировать товар → загрузить новое фото → Сохранить

### 2. Можно ли добавить несколько фото к одному товару?
- Да! В базе данных есть таблица `product_images` (галерея)
- Но через админ-панель пока работает только одно фото
- Для нескольких фото используйте API или БД напрямую

### 3. Что делать, если фото не отображается?
1. Проверьте, что `isMain = true` в таблице `product_images`
2. Проверьте, что URL корректный (откройте в браузере)
3. Очистите кеш браузера (Ctrl+Shift+R)
4. Проверьте в админ-панели, что фото загружено

### 4. Как использовать свои фотографии, а не из интернета?
- Загрузите через админ-панель: выберите файл с компьютера
- Фото автоматически конвертируется в base64 и сохранится в БД

### 5. Сколько блюд можно добавить?
- Неограниченно! База данных PostgreSQL поддерживает тысячи товаров

## 🚀 Проверка:

После добавления фотографии:

1. **Проверьте в админ-панели:**
   - Откройте `/admin/menu`
   - Фото должно отображаться в списке

2. **Проверьте на сайте:**
   - Откройте `/menu`
   - Найдите ваше блюдо
   - Фото должно отображаться в карточке товара

3. **Если не видно:**
   - Обновите страницу с очисткой кеша: `Ctrl + Shift + R`
   - Подождите 1-2 минуты (Vercel может кешировать)
