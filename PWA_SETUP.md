## 🧪 Тестирование PWA:

### Chrome DevTools:

1. Откройте Chrome DevTools (F12)
2. Перейдите на вкладку **Application**
3. Проверьте:
   - **Manifest** - должен отображаться корректно
   - **Service Workers** - должен быть зарегистрирован

1. В Chrome DevTools откройте **Lighthouse**
2. Выберите категорию **Progressive Web App**
3. Запустите проверку

1. Откройте сайт в Chrome на Android/Desktop
2. Должен появиться промпт "Установить приложение"
3. Нажмите "Установить"
4. Приложение появится на главном экране/в меню Пуск

- 📴 Офлайн режим (кэшированные страницы доступны)

- 📱 Full-screen режим (без браузерных UI элементов)

### 🎯 Стратегия кэширования:

**Network First:**
- Сначала пытается загрузить из сети
- Если сеть недоступна, использует кэш
- API запросы не кэшируются

**Кэшируются:**
- HTML страницы
- Статические файлы (CSS, JS)
- Изображения
- Шрифты

**Не кэшируются:**
- `/api/*` запросы
- `/_next/*` внутренние Next.js файлы
- POST/PUT/DELETE запросы

## 🔧 Настройка:

### Изменить цвет темы:

Отредактируйте `public/manifest.json`:

```json
{
  "theme_color": "#ff4d00",
  "background_color": "#ffffff"
}
```

### Добавить shortcuts:

В `public/manifest.json` добавьте в массив `shortcuts`:

```json
{
  "name": "Акции",
  "url": "/promos",
  "icons": [{ "src": "/icons/icon-192x192.png", "sizes": "192x192" }]
}
```

### Настроить кэш:

Отредактируйте `public/sw.js`:

```javascript
const CACHE_NAME = 'sushi-jaim-v2'; // Измените версию
const STATIC_CACHE = [
  // Добавьте файлы для кэширования
  '/custom-page',
];
```

## 🐛 Решение проблем:

### Service Worker не регистрируется

**Причина:** PWA работает только через HTTPS или localhost

**Решение:** 
- Локально: используйте `http://localhost:3000`
- Production: убедитесь, что сайт использует HTTPS

### Иконки не отображаются

**Причина:** Иконки не сгенерированы

**Решение:**
```bash
npm run generate:icons
```

### Офлайн режим не работает

**Причина:** Service Worker еще не закэшировал страницы

**Решение:**
1. Откройте сайт
2. Подождите 1-2 секунды (для кэширования)
3. Попробуйте офлайн режим снова

### Промпт установки не появляется

**Причины:**
- PWA уже установлено
- Браузер не поддерживает (Safari < 16.4)
- Промпт был отклонен ранее

**Решение:**
- Chrome: chrome://apps → удалите приложение
- Очистите localStorage
- Используйте инкогнито режим
