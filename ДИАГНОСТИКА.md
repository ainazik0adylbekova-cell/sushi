## Проблема 1: Неправильный API-адрес

### Проверка:
Убедитесь что API endpoints правильные:

```javascript
// В AuthProvider.tsx должны быть такие URL:
/api/auth/login      - для входа
/api/auth/register   - для регистрации
/api/auth/logout     - для выхода
/api/auth/me         - для получения текущего пользователя
```

### Как проверить в браузере:
1. Откройте DevTools (F12)
2. Перейдите на вкладку "Network"
3. Попробуйте зарегистрироваться
4. Найдите запрос к `/api/auth/register`
5. Проверьте:
   - ✅ Статус должен быть 201 (Created) при успехе
   - ❌ Если 404 - неправильный URL
   - ❌ Если 500 - ошибка сервера (см. Проблему 2)

### Тестирование через curl:
```bash
# Проверка доступности API
curl http://localhost:3000/api/auth/register

# Тест регистрации
curl -X POST http://localhost:3000/api/auth/register ^
  -H "Content-Type: application/json" ^
  -d "{\"name\":\"Test\",\"email\":\"test@test.com\",\"password\":\"test123456\"}"
```

## Проблема 2: Ошибка базы данных

### Шаг 1: Проверка подключения к базе

**Запустите:** `test-db.bat` или `node test-db-connection.js`

Скрипт проверит:
- ✅ Подключение к PostgreSQL
- ✅ Существование таблиц
- ✅ Наличие ролей
- ✅ Количество пользователей

### Возможные ошибки:

#### Ошибка 1: "Can't reach database server"
```
❌ ОШИБКА: Can't reach database server at `...`
```

**Причина:** База данных недоступна

**Решение:**
1. Проверьте `DATABASE_URL` в файле `.env`
2. Убедитесь что база данных запущена
3. Проверьте правильность хоста, порта, логина и пароля

**Ваш DATABASE_URL должен быть такого вида:**
```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE?sslmode=require
```

**Пример для Neon:**
```
postgresql://neondb_owner:npg_xxx@ep-xxx.aws.neon.tech/neondb?sslmode=require
```

#### Ошибка 2: "Table does not exist"
```
❌ ОШИБКА: Table "public"."User" does not exist
```

**Причина:** Таблицы не созданы в базе данных

**Решение:** Выполните миграцию
```bash
# Через PowerShell с обходом политики
powershell -ExecutionPolicy Bypass -Command "npx prisma db push"

# Или через батник:
@echo off
npx prisma db push
pause
```

**Сохраните команду в файл `migrate.bat` и запустите**

#### Ошибка 3: "Authentication failed"
```
❌ ОШИБКА: Authentication failed for user "..."
```

**Причина:** Неверный логин или пароль

**Решение:**
1. Проверьте логин и пароль в `DATABASE_URL`
2. Убедитесь что пользователь существует в базе
3. Проверьте права доступа пользователя

#### Ошибка 4: Нет роли "Пользователь"
```
⚠️ Нет ролей в базе!
```

**Решение:** Скрипт автоматически создаст роль, но вы можете создать вручную:

```sql
-- Подключитесь к базе и выполните:
INSERT INTO roles (id, name, description) 
VALUES (
  gen_random_uuid(), 
  'Пользователь', 
  'Обычный пользователь'
);
```

## Структура базы данных

### Таблица: users
```sql
CREATE TABLE users (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name        VARCHAR(100) NOT NULL,
  email       VARCHAR(255) UNIQUE,
  phone       VARCHAR(20) UNIQUE,
  password    VARCHAR(255) NOT NULL,
  roleId      UUID NOT NULL REFERENCES roles(id),
  isActive    BOOLEAN DEFAULT TRUE,
  isVerified  BOOLEAN DEFAULT FALSE,
  createdAt   TIMESTAMP DEFAULT NOW()
);
```

```sql

  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name        VARCHAR(50) UNIQUE NOT NULL,

);
```

## Частые проблемы и решения

### Проблема: "Не удалось подключиться к серверу"
**Решение:**
1. Убедитесь что `npm run dev` запущен
2. Проверьте что сервер на порту 3000
3. Откройте http://localhost:3000 в браузере

### Проблема: "Prisma Client is not configured"
**Решение:**
```bash
npx prisma generate
```

### Проблема: "Role with id ... does not exist"
**Решение:**
Создайте роль в базе данных (см. выше)

### Проблема: Пользователь создаётся, но не может войти
**Причина:** Пароли не совпадают (проблема с хешированием)

**Проверка:**
```javascript
const bcrypt = require('bcryptjs');

// Проверьте что хеш создаётся правильно
const hash = bcrypt.hashSync('test123', 10);
console.log('Hash:', hash);

// Проверьте что проверка работает
const valid = bcrypt.compareSync('test123', hash);
console.log('Valid:', valid); // должно быть true
```
