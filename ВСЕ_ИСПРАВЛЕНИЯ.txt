════════════════════════════════════════════════════════════════
  🚀 ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС (по порядку):
════════════════════════════════════════════════════════════════

1. ИНИЦИАЛИЗАЦИЯ РОЛЕЙ (один раз!)
   
   Дважды кликните:
   → init-roles.bat
   
   Это создаст роли "Пользователь" и "Администратор" в БД

2. НАСТРОЙКА GOOGLE OAUTH (если хотите Google вход)
   
   Откройте: https://console.cloud.google.com/apis/credentials
   
   Добавьте в "Authorized redirect URIs":
   → http://localhost:3000/api/auth/google/callback
   
   Подробнее: НАСТРОЙКА_GOOGLE_CLOUD.md

3. ПЕРЕЗАПУСК СЕРВЕРА (ОБЯЗАТЕЛЬНО!)
   
   В терминале:
   → Ctrl+C (остановить)
   → npm run dev (запустить)

4. ТЕСТИРОВАНИЕ
   
   Откройте: http://localhost:3000
   
   Попробуйте:
   
   А) Регистрация:
      → http://localhost:3000/register
      → Заполните форму
      → Нажмите "Зарегистрироваться"
   
   Б) Вход через Google:
      → http://localhost:3000/login
      → Нажмите "Войти через Google"
      → Выберите аккаунт
   
   В) Оплата Finik Pay:
      → Добавьте товары в корзину
      → Оформите заказ
      → Нажмите "Оплатить 5 сом"

════════════════════════════════════════════════════════════════
  🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
════════════════════════════════════════════════════════════════

Регистрация не работает:
  → Запустили init-roles.bat?
  → Перезапустили сервер?
  → Проверьте консоль на ошибки

Google OAuth не работает:
  → .env исправлен? (без пробелов)
  → Redirect URI настроен в Google Cloud?
  → Перезапустили сервер?
  → Подождали 1-2 минуты после настройки?

Finik Pay не работает:
  → Пользователь авторизован?
  → Prisma клиент сгенерирован?
  → Заказ создан в БД?

База данных не работает:
  → DATABASE_URL правильный в .env?
  → npm run db:push
  → npm run db:generate
